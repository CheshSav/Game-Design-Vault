## Combat

  

The way combat works

  

Actions:

-   Attack with Weapon(s)
    
-   Use Ability
    
-   Use Magic
    
-   Use Item
    
-   Command
    
-   Wait
    
-   Flee
    

  

Attack

-   Determine Hit Success: Die roll + Dex + Skill + Misc vs. Base + Dodge + Armor + Misc
    
-   Determine Crit Chance: Base + Per + Skill +  Misc
    
-   Determine Damage: Die roll + Str + Skill + Misc
    
-   Determine Effect: Base + Misc vs. Die Roll + Con + Misc

## Arcane Spells (INT)

  

Uses Stamina and Components

  

**Cantrips:** Easy,  quick magic that can be used without preparation

  

**Spells:** More powerful and magic that requires preparation but can still be used in combat, can apply meta-magic

  

**Ritual:** Long, expensive magic that typically has a powerful and customizable effect

  

---

## Divine Intercessions (CHA)

  

Uses Reputation(?) and Sacrifices

  

**Prayers:** Easy,  quick magic that can be used without preparation

  

**Intercessions:** More powerful magic that requires preparation but can still be used in combat

  

**Ceremony:** Long, expensive magic that typically has a very powerful but specific effect
